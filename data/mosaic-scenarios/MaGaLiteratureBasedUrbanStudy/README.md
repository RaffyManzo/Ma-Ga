# MaGaLiteratureBasedUrbanStudy

This versioned folder documents the shape of the generated literature scenario. Concrete SUMO files, the Scenario-Convert SQLite database and run logs remain local under `tmp/` and are not versioned.

The scenario uses:

```text
real topology: reduced InTAS candidate_0045 subnetwork
mobility: deterministic synthetic passenger traffic simulated live by SUMO
MOSAIC integration: real SQLite database generated by Scenario-Convert
MA-GA integration: live snapshot assembly and runtime bridge
```

Generate and run the concrete scenario with:

```powershell
powershell -NoProfile -ExecutionPolicy Bypass `
  -File .\tools\intas-literature-scenario\quick_literature_workflow.ps1 `
  -ForceRebuild `
  -PrintDetailedLiveReport `
  -PrintSummary
```

Do not delete `tmp\mosaic-25.2`: it contains the local MOSAIC runtime required by `mosaic.bat`.
