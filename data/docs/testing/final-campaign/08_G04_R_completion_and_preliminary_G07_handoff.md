# Completamento G04-R e handoff alla prima G07

G04-R è formalmente pronta per la chiusura.

La run valida ha osservato la transizione `rsu_0 → rsu_1` a 81,8 s e ha correlato la transizione con decisioni remote applicate al veicolo probe. T-096 e T-098 sono PASS. T-091 resta parziale e T-094 non osservato.

Il core Java resta congelato. Il JAR runtime non è stato ricompiliato. Il primo tentativo è escluso come errore del test harness e non entra nelle conclusioni sperimentali.

La prossima fase non è G02B. La sequenza operativa è:

1. eseguire una prima G07 sull'intera campagna disponibile fino a G04-R;
2. scrivere una prima bozza del capitolo sperimentale;
3. esportare un contesto ridotto, pulito e focalizzato, includendo il capitolo;
4. aprire una nuova conversazione;
5. creare un branch sperimentale dedicato e svolgere G02B;
6. valutare e integrare i risultati di G02B nel capitolo;
7. ripetere G07 in forma completa e definitiva.

Durante la prima G07 vanno mantenute distinte:

- le baseline FULL_MA_GA di G02;
- le evidenze funzionali G03–G06;
- la run mirata G04-R;
- i limiti non osservati;
- le varianti G02B ancora non eseguite.
