# Bandwidth Pool Capacity Audit

Suite: `data/snapshots/temporal/scenarios/comprehensive_dynamic_validation`.

This audit documents the final 18.3 bandwidth-pool catalog added to the synthetic dynamic-validation snapshots. Java DTOs and validators confirm the expected JSON shape: root `bandwidthPools`, gateway-level `bandwidthPoolId`, explicit `bandwidthPoolId` for `VEHICLE` candidates, and no pool on `LOCAL` candidates. `EDGE` and `CLOUD` candidates resolve bandwidth through the source vehicle active access link and the linked gateway.

No explicit infrastructure capacity source was found in repository docs/configuration outside the target JSON files. All capacities below therefore use the requested provisional migration rule: maximum observed `availableBandwidth` across the 27-snapshot sequence for the corresponding gateway or V2V pair.
